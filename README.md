# 💼 Job Portal

A modern full-stack Job Portal that connects job seekers with recruiters through a seamless and user-friendly platform. The system allows candidates to discover opportunities, apply for jobs, and track applications, while recruiters can post openings and manage applicants efficiently.

---

## 🚀 Overview

The Job Portal is designed to simplify the recruitment process for both candidates and employers. It provides a centralized platform where recruiters can post jobs and candidates can explore opportunities based on their skills and interests.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/job-portal.git
cd job-portal
```

### Install Frontend Dependencies

```bash
cd frontend
npm install
```

### Install Backend Dependencies

```bash
cd backend
```

For Spring Boot:

```bash
./mvnw spring-boot:run
```

For Node.js:

```bash
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file:
